# Fuentes de referencia

Estas fuentes inspiran el método, pero no sustituyen la revisión del proyecto concreto:

- https://github.com/addyosmani/web-quality-skills/tree/main/skills/web-quality-audit — auditoría basada en evidencia, medición renderizada y separación entre hallazgos verificados e hipótesis.
- https://github.com/thedaviddias/Front-End-Checklist — checklist amplia de frontend con categorías de HTML, CSS, JavaScript, performance, accesibilidad, SEO, seguridad, imágenes, testing, privacidad e internacionalización.
- https://github.com/magallon/website-audit-toolkit — protocolo por capas que incluye performance, accesibilidad, responsive, conversión, SEO, copywriting y revisión de diseño.

Usa estas referencias como marco de trabajo. No copies recomendaciones irrelevantes para el objetivo del sitio ni asumas que una checklist garantiza conversión.
